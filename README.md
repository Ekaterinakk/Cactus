## Мои работы
**1. Цветочный интернет-магазин "Cactus"**

"Cactus" - выдуманный интернет-магазин цветов, букетов, комнатных растений и подарков.

Проект представляет собой программный интерфейс - API, с помощью которого веб-сайт, мобильное приложение, панель администратора и внешние сервисы могут взаимодействовать с серверной частью магазина.

Цель: Разработка спецификации REST API для цветочного магазина «Cactus», обеспечивающей управление каталогом товаров, покупателями, заказами и доставкой, а также стандартизацию обмена данными между клиентскими приложениями, сервером магазина и внешними сервисами.
